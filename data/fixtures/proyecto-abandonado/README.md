# Gestor de tienda (proyecto pausado en marzo)

Sistema para administrar pedidos, pagos y reportes de la tienda.

## Uso

- `npm run start` levanta el servidor.
- `npm run lint` revisa el estilo (pendiente de configurar).
- Estado de pruebas: 12 pruebas en total.

## Estructura

- `src/index.js` — arranque principal.
- `src/api/ventas.js` — capa de ventas.
- `src/rutas/reportes.js` — reportes del negocio.
